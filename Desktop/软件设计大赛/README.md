# 课笺

给要把笔记背下来的人用的学习产品。打开首页时，「课」和「笺」从一条细缝展开成药丸，里面是一座浮岛。进去之后，今天的功能排成一条小路，不再是一排并列的页面。单词是一张可以翻转、跟着手倾斜的卡片。

## 运行

```powershell
cd go/server
go run .
```

打开 http://127.0.0.1:8080

首页的岛和瀑布来自一段循环视频，点药丸或「进去玩」进入里面。导航只留今天、单词、口语、我的。

演示账号：`demo@kejian.local` / `kejian-demo`

## 账号

注册、登录、退出、修改密码、忘记密码都可用。重置令牌只存 SHA-256，三十分钟有效，用过即失效。本机没有配置邮件时，忘记密码页会给出一次重置链接。设置 `KEJIAN_SMTP` 后不再把链接写回页面。

词册已放入四级、六级、考研、专四、专八、雅思、托福、托业、GRE、高考、日常和课程术语。设置页可以按「单词,音标,中文,例句」继续导入。
